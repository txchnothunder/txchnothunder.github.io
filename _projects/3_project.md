## Overview

A cross-functional data science project to forecast **wildfire smoke dispersion** using satellite and weather data, presented at the **2025 ICS Project Expo** at UC Irvine.

## My Role

Led a team of four as project coordinator — running weekly sprint meetings, aligning technical and temporal workstreams, and owning the geospatial pipeline.

## Pipeline

- **Data sources:** NOAA satellite imagery + Open-Meteo weather APIs
- **Processing:** Custom ETL pipeline integrating multi-source geospatial signals
- **Model:** XGBoost regression on spatiotemporal features

## Results

Outperformed linear baselines by **more than 2× in predictive accuracy** on held-out smoke dispersion events.

## Stack

Python · XGBoost · PostGIS · GeoPandas · Shapely · Open-Meteo API · NOAA API
