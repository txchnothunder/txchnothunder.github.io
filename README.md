# Ethan Wong | Portfolio

Personal portfolio site for Ethan Wong, a Master of Data Science student at UC Irvine.

Live site: https://txchnothunder.github.io

The site collects my resume, projects, and the posters and slides from my research and coursework, with plain-language summaries so anyone can follow the work.

## Built with

Plain HTML, CSS, and JavaScript with no build step. It is hosted on GitHub Pages and follows the visitor's light or dark mode setting.

## Structure

- `index.html` is the page layout
- `style.css` holds the styling
- `script.js` builds the page from the data files
- `data/resume.js` holds the intro, experience, education, and skills
- `data/projects.js` holds the projects and the files attached to each
- `assets/` holds the photo, resume PDF, and project files
